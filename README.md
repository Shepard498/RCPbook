# Recipe Ingredient Manager

React + Vite recipe and ingredient manager app.

## Local setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## GitHub

This repository was initialized locally in the workspace. To link it to a GitHub remote, add the remote URL and push:

```bash
git remote add origin https://github.com/Shepard498/REPO_NAME.git
git branch -M main
git push -u origin main
```
